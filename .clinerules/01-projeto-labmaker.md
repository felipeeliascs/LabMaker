# Projeto LabMaker

O LabMaker é um protótipo de ambiente educacional imersivo em 360 graus para práticas de robótica maker, programação visual, robótica virtual e educação STEAM na educação básica.

## Objetivo do MVP

Criar um tour 360 navegável, simples e funcional, com cenas educacionais, hotspots de navegação, hotspots de recursos, painel pedagógico e página de entrada para teste piloto.

## Stack obrigatória do MVP

- HTML
- CSS
- JavaScript
- A-Frame
- Projeto web estático
- Sem backend
- Sem banco de dados
- Sem login
- Sem framework pesado

## Cenas planejadas

1. Antesala / Recepção
2. Hub Central
3. Programação e Robótica
4. Eletrônica e Prototipagem
5. Fabricação Digital
6. Arena de Batalha de Robôs

## Público-alvo

Estudantes do Ensino Fundamental II e Ensino Médio, especialmente em contextos escolares com limitação de infraestrutura laboratorial.

## Natureza do produto

Este projeto não é um sistema comercial completo. É um protótipo educacional de mestrado, com foco em viabilidade, usabilidade, engajamento, percepção pedagógica e refinamento.
