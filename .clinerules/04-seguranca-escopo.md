# Segurança, Escopo e Pesquisa

## Segurança

1. Não criar nem solicitar chaves de API.
2. Não criar arquivos `.env` com dados reais.
3. Não coletar dados pessoais de estudantes.
4. Não inserir dados identificáveis no código.
5. Não criar formulários reais de pesquisa sem aprovação ética.
6. Usar apenas placeholders para formulários até autorização.

## Ética da pesquisa

Qualquer coleta real de dados com estudantes depende de aprovação ética, TCLE, TALE, participação voluntária e anonimização.

## Escopo do MVP

O MVP deve focar em:

- tour 360 navegável;
- cenas educacionais;
- hotspots de navegação;
- hotspots de recursos;
- painel pedagógico;
- página piloto simples;
- documentação técnica e pedagógica.

## Fora de escopo

- gamificação avançada;
- analytics;
- ranking;
- login;
- cadastro de estudantes;
- banco de dados;
- integração com sistemas externos;
- multiplayer;
- coleta científica definitiva.
