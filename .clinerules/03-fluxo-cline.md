# Fluxo de Trabalho com Cline

## Regra principal

Antes de editar qualquer arquivo, sempre apresentar plano.

## Modo Plan

Quando o usuário pedir uma tarefa, primeiro responder com:

1. entendimento da tarefa;
2. arquivos que pretende criar ou alterar;
3. plano em etapas;
4. riscos;
5. critérios de pronto;
6. testes manuais necessários;
7. dúvidas antes de implementar.

Não editar arquivos no Plan Mode.

## Modo Act

Só implementar após aprovação explícita do usuário.

Ao finalizar uma implementação, responder com:

1. arquivos alterados;
2. resumo das mudanças;
3. como testar;
4. riscos restantes;
5. sugestão de mensagem de commit.

## Proibições

- Não implementar escopo não solicitado.
- Não refatorar arquitetura sem autorização.
- Não criar backend.
- Não criar login.
- Não criar banco de dados.
- Não criar dashboard administrativo.
- Não instalar pacotes sem pedir autorização.
- Não alterar arquivos fora da tarefa atual.
